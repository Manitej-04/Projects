# Netflix Dashboard - Power BI Project

## 📊 Overview
This Power BI dashboard analyzes Netflix's content library to uncover trends in genre, country-wise production, and release timelines. It offers interactive visualizations to explore how Netflix's catalog has evolved over time.

## 🖼️ Report Preview
![Netflix Dashboard Preview](https://github.com/Manitej-04/Projects/blob/main/Netflix/Dashboard.png)

## 📂 Files
- **NetflixDashboard.pbix** – Interactive Power BI report.
- **Dashboard.png** – Preview of the dashboard visuals.

## 🔍 Features
- Genre-based content analysis
- Country-wise content production breakdown
- Release year trends for movies and TV shows
- Interactive filters, slicers, and KPIs for deeper insights

## 🚀 How to Use
1. Download `NetflixDashboard.pbix` from this repository.
2. Open it using **Power BI Desktop**.
3. Explore the dashboard with built-in filters and visuals.

## ⚠️ Important Notes
- GitHub cannot preview `.pbix` files directly.
- Use **Power BI Desktop** to view and interact with the report.
