# Netflix Dashboard - Power BI Project

## 📊 Overview
This repository features a Power BI dashboard that provides insights into Netflix's content library, including release trends, genre distribution, and country-wise content analysis.

## 🖼️ Report Preview
![Netflix Dashboard Preview](https://raw.githubusercontent.com/Manitej-04/Netflix-EDA/main/netflix_dashboard_preview.png)

## 📂 Files
- **NetflixDashboard.pbix** – The interactive Power BI report file.

## 🔍 Features
- Genre-based content analysis
- Country-wise content breakdown
- Trends over time: movie vs TV show release patterns
- Interactive filters and visuals (date slicers, bar charts, KPIs)

## 🚀 How to Use
1. Download `NetflixDashboard.pbix`.
2. Open it using **Power BI Desktop**.
3. Interact with the filters and visuals to explore insights.

## ⚠️ Important Notes
- `.pbix` files cannot be previewed directly on GitHub. Please **download** the file and open in Power BI Desktop.
- Export visuals to PDF or PNG for presentations or sharing if you're not using Power BI Service.
